# Third-party material

## ArduPilot

`ardupilot/data/upstream/` contains material from the ArduPilot project
(https://github.com/ArduPilot/ardupilot), licensed under the GNU General Public
License v3.0 (copy in `ardupilot/data/upstream/ARDUPILOT_LICENSE.txt`):

- `frame_params/`: reference parameter files from `Tools/Frame_params`, copied unmodified.
  Authors are the contributors and manufacturers named in each file.
- `copter_params.json`: ArduCopter parameter documentation generated by ArduPilot's own
  `Tools/autotest/param_metadata/param_parse.py`.
- `SOURCE.json` records the exact upstream commit. Current: ArduCopter V4.7.2,
  commit fb773567896014da007bca58358704d4a0d8516f (tag `ArduCopter-stable`).

Refresh with `python ardupilot/tools/fetch_upstream.py`.
